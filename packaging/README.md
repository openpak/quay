# Quay artwork

`quay.svg` is the original supplied by tobagin from Downloads on 2026-10-17.
Its copyright and AGPL-3.0-only notice are retained in the SVG. `quay.png` is
the 256-pixel rasterization supplied alongside the same artwork under the same
license. Both image formats are distributed separately from the emulator
binary, never embedded into it. The desktop entry uses the `org.openpak.quay`
icon name. Installation into a desktop icon theme is not performed by the
build wrapper.
